# GraphRAG 多模态知识问答系统 — 产品需求文档 v1.0

---

## 1. 项目概述

### 1.1 核心目标

构建一个**基于知识图谱的多模态文档问答系统**，让用户上传任意格式的文档（PDF、Word、PPT、Excel、图片、HTML），系统自动完成文档解析、结构化信息抽取、知识图谱构建，并提供基于图谱的智能问答能力，回答附带数据溯源。

**一句话定位**：上传文档，自动建图谱，精准问答带溯源。

### 1.2 核心场景

| 场景 | 描述 | 典型用户行为 |
| --- | --- | --- |
| 财务分析 | 上传年报/季报 PDF，提问各季度营收、利润、毛利率等数值 | "Q1 到 Q4 的营业收入分别是多少？" |
| 研究文献 | 上传学术论文，提问研究方法、实验结果、作者关系 | "这篇论文的主要发现是什么？" |
| 合同审查 | 上传合同文档，提问关键条款、责任方、时间节点 | "甲方的违约责任是什么？" |
| 竞品分析 | 上传竞品报告 PPT，提问市场数据、对比指标 | "竞品 A 和 B 的市场份额对比？" |
| 数据报表 | 上传 Excel 数据表，提问汇总统计、趋势变化 | "全年销售额最高的产品是哪个？" |

### 1.3 业务痛点

| 痛点 | 现状 | 本系统解决方式 |
| --- | --- | --- |
| 文档格式多样，人工阅读效率低 | 需要逐页翻阅 PDF/PPT/Excel | 自动解析所有格式，统一为结构化知识 |
| 数值散落在表格/正文中，难以快速定位 | 手动 Ctrl+F 搜索，容易遗漏 | KG 精确索引每个数值，带行列语义 |
| 传统 RAG 只做文本匹配，缺乏关系理解 | 返回相关段落但不理解实体间关系 | 知识图谱建模实体+关系，支持推理 |
| 回答缺乏可信度，无法溯源 | LLM 可能编造数据 | 每个回答附带 entity_id + 原文位置 |
| 多轮对话缺乏上下文 | 每次提问都要重复背景 | 后端 session 管理，自动拼接历史 |

### 1.4 面向用户群体

| 用户角色 | 使用频率 | 核心诉求 |
| --- | --- | --- |
| 研究员/分析师 | 高频（每日） | 快速从论文/报告中提取数据和关系 |
| 财务人员 | 中频（周/月） | 精准查询财务指标，对比不同周期 |
| 产品经理 | 中频 | 从竞品报告中提取关键信息 |
| 法务人员 | 低频 | 合同条款快速检索 |
| 管理层 | 低频 | 快速了解报告核心结论 |

### 1.5 成功标准

| 维度 | 指标 |
| --- | --- |
| 功能完整性 | 上传 → 索引 → 问答 → 溯源 全链路跑通 |
| 数值精度 | 表格数值 100% 精确还原（实测已验证） |
| 响应速度 | 问答首 token ≤ 3s；5 页文档索引 ≤ 60s |
| 溯源可靠性 | 每个回答附带 entity_id + document_id |
| 多轮理解 | "Q4 呢？"能正确理解为延续上一轮的指标查询 |

## 2. 产品流程

### 2.1 端到端主流程

```text
[入口] 用户打开系统
   │
   ├─ 首次使用（无文档）→ 空状态引导 → 上传第一个文档
   │
   ├─ 有文档 → 文档列表展示
   │
   ▼
[步骤 1] 上传文档
   用户点击"+ 上传" → 弹出拖拽区 → 选择/拖入文件
   → 前端校验（类型 + 大小）
   → POST /api/documents → 返回 {document_id, task_id, events_url}
   → 关闭上传弹层
   → 左栏新增文档条目（status=pending）
   │
   ▼
[步骤 2] 索引进度
   前端自动连接 SSE events_url
   → 中栏切换为"索引进度"视图
   → 三阶段进度条实时更新：
     [解析] MinerU 文档解析（parsing）
     [抽取] LangExtract 信息抽取（extracting）
     [建图] 知识图谱构建（building_kg）
   → 每阶段完成打勾 + 显示耗时
   → 失败时显示错误信息
   │
   ▼
[步骤 3] 索引完成
   SSE 推送 complete 事件
   → 文档状态变 ready
   → 左栏状态 pill 变绿
   → 自动创建默认会话
   → 中栏切换为问答视图
   → 右栏加载知识图谱（GET /api/documents/{id}/kg）
   │
   ▼
[步骤 4] 问答交互
   用户在输入框输入问题 → 按回车/点击发送
   → 中栏追加 user 气泡
   → POST /api/sessions/{id}/messages（stream=true）
   → SSE 推送 tool_call 事件 → 显示工具调用标签
   → SSE 推送 token 事件 → 逐字追加到 assistant 气泡
   → SSE 推送 complete 事件 → 气泡定型 + 来源引用 + 耗时
   → 右栏图谱高亮本次涉及的节点
   │
   ▼
[步骤 5] 多轮对话
   用户继续提问（如"Q4 呢？"）
   → 后端自动拼接历史上下文
   → 重复步骤 4
   │
   ▼
[步骤 6] 会话管理
   用户可创建新会话 / 切换历史会话 / 删除会话
   │
   ▼
[步骤 7] 文档管理
   用户可上传更多文档 / 切换文档 / 删除文档
   → 切换文档时右栏图谱同步切换
   → 删除文档级联删除所有会话
```

### 2.2 异常流程

| 异常场景 | 系统行为 | 用户感知 |
| --- | --- | --- |
| 上传不支持的文件类型 | 前端拦截，toast 提示 | "不支持该文件格式" |
| 文件超过 200MB | 前端拦截，toast 提示 | "文件大小超过限制" |
| MinerU 解析失败 | SSE 推送 error 事件 | 进度条变红 + 错误原因 |
| LangExtract 抽取失败 | SSE 推送 error 事件 | 同上 |
| LLM 超时 | 气泡显示错误 + 重试按钮 | "回答生成超时，点击重试" |
| SSE 断线 | 自动重连 3 次（2/4/8s） | 短暂无感；3 次失败后提示"连接中断" |
| 对未 ready 文档提问 | 后端返回 409 | 前端禁用输入框 + 提示"文档正在索引中" |

### 2.3 数据流向

```text
用户上传文件
  → [后端] 落盘 data/documents/{id}/source.pdf
  → [subprocess] MinerU 解析 → data/documents/{id}/mineru/
  → [subprocess] LangExtract 抽取 + KG 构建 → data/documents/{id}/kg/
  → [后端] 加载 KG 到内存缓存
  → [前端] 获取 KG JSON → D3.js 渲染图谱
  → [前端] 用户提问 → [后端] Agent 查询 KG → 流式返回答案
```

## 3. 关键页面/模块清单

### 3.1 页面状态矩阵

| 状态 | 左栏 | 中栏 | 右栏 |
| --- | --- | --- | --- |
| 无文档 | 空列表 + 上传引导 | 居中上传引导 | 隐藏或"暂无图谱" |
| 有文档，未选中 | 文档列表 | 选择文档提示 | 隐藏 |
| 选中文档，索引中 | 文档列表（当前项高亮） | 索引进度面板 | "索引完成后展示" |
| 选中文档，ready | 文档列表 | 问答对话 | 知识图谱 |
| 选中文档，failed | 文档列表 | 错误信息 + 重试 | 隐藏 |

### 3.2 模块设计说明

#### 模块 A：TopBar（顶部导航栏）

- 高度 44px，固定顶部
- 左侧：Logo（图标 + "GraphRAG" 文字）
- 右侧：系统健康状态指示灯（绿点 = 正常）
- 功能：品牌标识 + 全局状态一览

#### 模块 B：Sidebar（左栏文档库）

- 宽度 220px，可折叠
- 顶部：标题"文档库" + "上传"按钮
- 中部：文档列表（滚动）
  - 每项：文件名 + 状态 pill + KG 统计（实体数/边数）
  - 状态 pill 颜色：就绪（绿）/ 解析中（琥珀+百分比）/ 失败（红）
  - 当前选中项高亮背景
- 底部：文档总数统计
- 交互：点击切换文档；右键/长按删除

#### 模块 C：ChatPanel（中栏问答面板）

- 弹性宽度（min 400px）
- 顶部：当前文档名 + KG 统计 + 会话 tab 切换 + "新会话"按钮
- 中部：消息列表（滚动）
  - user 气泡：右对齐，主色背景
  - assistant 气泡：左对齐，surface 背景
  - 工具调用标签：气泡上方，绿色小标签
  - 来源引用：气泡下方，灰色引用块
  - 打字动画：三点跳动
- 底部：输入框 + 发送按钮
  - 输入框自适应高度（1-5 行）
  - 回车发送，Shift+回车换行

#### 模块 D：IndexProgress（索引进度面板）

- 替代 ChatPanel 在文档索引期间显示
- 三阶段进度条（parsing → extracting → building_kg）
- 每阶段：图标 + 名称 + 百分比 + 状态（进行中/完成/失败）
- 完成阶段显示耗时
- 失败时：红色错误信息 + 错误码

#### 模块 E：KGPanel（右栏知识图谱）

- 宽度 420px，可折叠
- 顶部：标题"知识图谱" + 实体数/关系数统计
- 中部：D3.js 力导向图
  - 节点按 entity_class 着色
  - 节点大小按连接数加权
  - 边显示 predicate 标签（hover 时）
  - 支持拖拽、缩放、平移
  - 问答联动：回答涉及的节点高亮发光
- 底部：图例（entity_class → 颜色映射）
- 交互：点击节点弹出 tooltip（label + properties + sources）

#### 模块 F：UploadOverlay（上传弹层）

- 半透明遮罩 + 居中卡片
- 拖拽区：虚线边框 + 上传图标 + 提示文字
- 支持格式提示：PDF / Word / PPT / Excel / 图片 / HTML
- 大小限制提示：≤ 200MB
- 拖入文件时边框变色
- 选择文件后立即上传并关闭

## 4. 关键节点交互逻辑

### 4.1 文档上传交互

```
触发：点击"+ 上传"按钮 或 拖拽文件到页面任意位置
  → 显示 UploadOverlay
  → 用户选择/拖入文件
  → 前端校验：
     - 文件类型是否在支持列表中？否 → toast "不支持该格式"
     - 文件大小 ≤ 200MB？否 → toast "文件过大"
  → 校验通过 → 调用 POST /api/documents
  → 上传中：按钮变为 loading 状态
  → 上传成功（HTTP 201）：
     - 关闭 overlay
     - 左栏追加新文档条目（status=pending）
     - 自动选中该文档
     - 中栏切换为 IndexProgress
     - 连接 SSE events_url
  → 上传失败：toast 显示错误信息
```

### 4.2 索引进度交互

```
SSE 连接建立后：
  stage_start 事件 → 对应阶段变为"进行中"（琥珀色 + 动画）
  progress 事件 → 更新百分比 + detail 文字
  stage_done 事件 → 对应阶段变为"完成"（绿色 + 勾 + 耗时）
  complete 事件 → 
     - 所有阶段完成
     - 左栏状态 pill 变绿
     - 延迟 500ms 后自动切换到问答视图
     - 右栏加载图谱
  error 事件 →
     - 当前阶段变红
     - 显示错误信息
     - 左栏状态 pill 变红
```

### 4.3 问答流式交互

```
用户按回车发送问题：
  → 输入框清空 + 禁用（防重复提交）
  → 追加 user 气泡（立即可见）
  → 追加 assistant 占位（打字动画）
  → 建立 SSE 连接

  tool_call 事件 →
     - 打字动画上方插入工具标签（如 ⚡ find_metrics）
     - 标签状态：调用中（脉冲动画）

  tool_result 事件 →
     - 工具标签变为完成状态（静态）

  token 事件 →
     - 移除打字动画（首个 token 时）
     - 逐字追加到 assistant 气泡
     - 自动滚动到底部

  complete 事件 →
     - 气泡内容定型
     - 追加来源引用块
     - 显示耗时标签
     - 输入框恢复可用
     - 右栏图谱高亮涉及节点（300ms 放大 + glow，2s 后恢复）

  error 事件 →
     - 移除打字动画
     - 显示错误气泡 + "重试"按钮
     - 输入框恢复可用
```

### 4.4 图谱联动交互

```
问答完成后：
  从 complete 事件的 tool_calls 中提取 entity_id / metric_name / group
  → 在图谱中找到对应节点
  → 节点放大 1.5x + 添加 glow filter（300ms ease-out-quart）
  → 2s 后恢复原始大小（300ms ease-out）
  → 如果节点不在视口内，自动平移图谱使其可见

点击图谱节点：
  → 弹出 tooltip（固定在节点旁）
  → 显示：label / entity_class / properties 键值对 / sources（document_id + 位置）
  → 点击其他位置关闭 tooltip
```

### 4.5 会话切换交互

```
点击会话 tab：
  → 当前会话消息列表替换为目标会话
  → GET /api/sessions/{id}/messages 加载历史
  → 加载中显示骨架屏
  → 加载完成渲染所有历史气泡

点击"+ 新会话"：
  → POST /api/sessions（绑定当前 document_id）
  → 新增 tab + 切换到空对话
  → 显示欢迎消息

删除会话（右键 tab）：
  → 确认弹窗"删除后不可恢复"
  → DELETE /api/sessions/{id}
  → 移除 tab + 切换到相邻会话
```

### 4.6 文档切换交互

```
点击左栏另一个文档：
  → 如果目标文档 status=ready：
     - 切换中栏为该文档的问答视图
     - 加载该文档的会话列表
     - 右栏重新加载该文档的 KG
  → 如果目标文档 status=parsing/extracting/building_kg：
     - 切换中栏为 IndexProgress
     - 连接该文档的 SSE events_url
  → 如果目标文档 status=failed：
     - 中栏显示错误信息
```

## 5. UI 布局、配色与组件样式

### 5.1 整体布局

```
┌─────────────────────────────────────────────────────────────┐
│ TopBar (44px, 固定)                                          │
├──────────┬──────────────────────────────┬───────────────────┤
│ Sidebar  │ ChatPanel / IndexProgress    │ KGPanel           │
│ 220px    │ flex:1 (min 400px)           │ 420px             │
│ 固定     │ 弹性                          │ 固定              │
│ 可折叠   │                              │ 可折叠            │
└──────────┴──────────────────────────────┴───────────────────┘
```

### 5.2 配色方案（深色精密，OKLCH）

**色彩策略**：Restrained（tinted neutrals + 一个青蓝主色 ≤10%）

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 背景 | `oklch(0.12 0.008 260)` | 页面底色 |
| 面板 | `oklch(0.16 0.01 260)` | 侧栏/顶栏 |
| 容器 | `oklch(0.19 0.01 260)` | 输入框/气泡 |
| 交互态 | `oklch(0.22 0.01 260)` | hover/active |
| 分割线 | `oklch(0.26 0.01 260)` | 边框 |
| 主文本 | `oklch(0.92 0.005 260)` | 正文 |
| 次文本 | `oklch(0.65 0.008 260)` | 辅助信息 |
| 弱文本 | `oklch(0.42 0.008 260)` | 标签/时间 |
| 主色 | `oklch(0.65 0.18 200)` | 按钮/链接/高亮 |
| 成功 | `oklch(0.65 0.16 155)` | 就绪/完成 |
| 警告 | `oklch(0.72 0.16 80)` | 进行中 |
| 错误 | `oklch(0.62 0.18 25)` | 失败 |

**禁止**：纯黑 `#000` / 纯白 `#fff`。所有中性色向 hue 260 偏移（chroma 0.005-0.01）。

### 5.3 响应式断点

| 断点 | 布局变化 | 具体行为 |
| --- | --- | --- |
| ≥1200px | 三区完整 | 220 + flex + 420 |
| 768–1199px | 右栏折叠 | KGPanel 变为右侧滑入面板（覆盖中栏 60%），中栏右上角出现"图谱"按钮 |
| <768px | 单栏 | 左栏变底部 tab；中栏全屏；图谱为顶部 tab 切换 |

### 5.4 组件样式规范

#### 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 | 背景 `--accent`，白色文字，圆角 5px，padding 5px 10px |
| 次按钮 | 透明背景，`--accent` 边框 + 文字，圆角 5px |
| 危险按钮 | 背景 `--red`，白色文字 |
| 禁用态 | opacity 0.4，cursor not-allowed |

#### 输入框

- 背景 `--surface-2`，边框 `--border`，圆角 8px
- focus 时边框变 `--accent-dim`
- placeholder 颜色 `--text-3`
- 自适应高度（textarea，min 38px，max 120px）

#### 气泡

| 角色 | 样式 |
| --- | --- |
| user | 背景 `--accent-dim`，右对齐，圆角 10px 10px 2px 10px |
| assistant | 背景 `--surface-2`，左对齐，圆角 10px 10px 10px 2px |

#### 状态 Pill

- 圆角 10px，padding 1px 6px，font-size 10px
- 就绪：背景 `oklch(0.25 0.06 155)`，文字 `--green`
- 解析中：背景 `oklch(0.25 0.06 80)`，文字 `--amber`
- 失败：背景 `oklch(0.25 0.06 25)`，文字 `--red`

#### 工具调用标签

- 背景 `oklch(0.22 0.05 155)`，文字 `--green`
- 圆角 4px，font-size 10px
- 前缀 ⚡ 图标

#### 来源引用块

- 背景 `--surface`，左边框 2px `--accent-dim`
- 圆角 4px，font-size 10px，颜色 `--text-3`

### 5.5 动效规范

| 场景 | 曲线 | 时长 |
| --- | --- | --- |
| 面板折叠/展开 | ease-out-quart | 200ms |
| 气泡出现 | ease-out（opacity + translateY 8px） | 150ms |
| 进度条推进 | ease-out | 400ms |
| 图谱节点高亮 | ease-out-quart（r 放大 + glow） | 300ms |
| 工具标签出现 | ease-out（opacity + scale 0.95→1） | 120ms |
| 上传 overlay | ease-out（opacity + backdrop-filter） | 200ms |

统一曲线：`cubic-bezier(0.25, 1, 0.5, 1)`（ease-out-quart）。不使用 bounce / elastic。

### 5.6 字体与排版

- 系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif`
- 代码字体：`"SF Mono", "Cascadia Code", "Fira Code", monospace`
- 基础字号：13px
